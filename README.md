# Prime Hospital Website Frontend

Official frontend portal for Prime Hospital, located at Hospital Chowk, Biratnagar-7, Koshi Province, Nepal.

## Structure

- `index.html`: Main single-page hospital portal
- `style.css`: Responsive design system and visual styles
- `script.js`: Dynamic rendering, slider controls, and form handling
- `404.html`: Custom fallback error page
- `manifest.json`: Web app manifest configuration
- `robots.txt`: Search crawler indexing directions
- `sitemap.xml`: Search engine sitemap

## Features

- Modern typography powered by Plus Jakarta Sans and Noto Sans Devanagari
- Dynamic hero carousel with automated transitions
- Interactive department catalog and doctor profiles
- Appointment booking and patient support forms with client-side validation
- Fully responsive navigation with mobile drawer support
- Interactive location map integration
